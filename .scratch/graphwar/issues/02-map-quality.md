# D02 — Качество и ограничения случайных карт

**Статус:** resolved (решение владельца, 2026-10-21)

## Question

Какие случайные карты считать «хорошими»: симметрия, число и размер препятствий, гарантировать ли проходимость между сторонами.

## Proposed Answer (агент)

1. **Симметрия:** поворотная на 180° — каждое препятствие имеет пару-зеркало `(x,y)→(100−x, 60−y)`; максимум одно самозеркальное строго в центре `(50,30)`. Спавн фиксированный, тоже зеркальный.
2. **Плотность:** 4–6 препятствий, радиусы 2–6; зазоры: препятствие–препятствие ≥ 1, препятствие–спавн ≥ 3.
3. **Проходимость:** НЕ гарантировать — сплошная стена легальна, как в оригинальном Graphwar.
4. Лимит попыток генерации (200) + проверенная запасная карта при исчерпании.

Альтернативы отклонены: свободная генерация без симметрии (нечестно), двойная симметрия (однообразно), обязательный BFS-проход (лишает легальные стены).
